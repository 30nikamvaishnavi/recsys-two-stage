Large-Scale Personalized Recommendation Engine

A CPU-oriented, two-stage MovieLens recommender: two-tower retrieval with FAISS followed by DCN-V2 or Wide & Deep ranking.

This GitHub Pages site is a static project overview. The interactive Streamlit, FastAPI, Triton, and Redis application is not hosted on GitHub Pages.

Project

The pipeline uses time-based data splits, point-in-time features, candidate retrieval, ranking, cold-start fallbacks, and CPU ONNX serving. It also includes Redis caching, an Airflow retraining workflow with an evaluation gate, and a simulated A/B test.

Verification notice

The earlier sample A/B simulation and load-test results are invalid: SMOKE-mode ONNX models were in the shared model repository, and both A/B arms fell back to popularity. Those results are not reported here. Any A/B test in this project is a simulation with no real users.
